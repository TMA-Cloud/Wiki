Recover deleted files and manage your trash in TMA Cloud.

## Trash System

### Soft Delete

- Deleting moves items to the trash; nothing is removed for good yet
- Items can be restored for 15 days, then the background worker deletes them
- Share links stop working for items in the trash

## Accessing Trash

### Trash Section

1. Open **Trash** in the sidebar
2. The list shows each deleted item and when it was deleted, newest first

## Restoring Files

### Single File Restore

1. Right-click the item in the trash
2. Select **Restore**

### Bulk Restore

Select several items and click **Restore**. A progress bar shows while they are restored.

### Restore Location

- Items go back to the folder they were deleted from
- If that folder is no longer there (or is itself in the trash), the item is restored to the root
- If the folder already holds an item with the same name, the restored item gets `(restored-…)` added to its name

## Permanent Deletion

<Callout type="error" title="Irreversible">
  Permanent deletion cannot be undone. Once a file is removed from trash (by you
  or by the 15-day cleanup), it cannot be recovered.
</Callout>

### Delete Permanently

1. Right-click the item in the trash
2. Select **Delete forever**
3. The deletion is queued and reports when it finishes

### Automatic Cleanup

Every day at 02:00 UTC, the background worker deletes items that have been in the trash for more than 15 days.

### Bulk Permanent Delete

Select several items and click **Delete forever**. The background worker removes them, and a progress bar shows while it runs.

## Storage Impact

Items in the trash still count toward your storage limit until they are deleted for good.
