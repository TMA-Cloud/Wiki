**Settings** → **Appearance** sets how TMA Cloud looks on this device. It is the same in
the web app and the desktop app.

## Theme

**System** follows your computer's light or dark setting. **Light** and **Dark** keep one
look. The sun or moon button in the header switches between light and dark too.

## Text Size

| Choice      | Size compared with Default |
| ----------- | -------------------------- |
| **Small**   | 90%                        |
| **Default** | 100%                       |
| **Large**   | 115%                       |
| **Larger**  | 130%                       |

Text, icons and spacing grow or shrink together, the way a browser zooms a page, so
nothing overlaps or is cut off. The change shows at once. The line under the choices is
a sample of a file name, with the letters and digits that are easiest to mix up.

Each device remembers its own choice: the desktop app for that computer, the web app
for that browser.

## The Font

TMA Cloud uses Inter, a font made for screens, with tall lowercase letters that stay
easy to read in long lists. Capital `I` has small bars at the top and bottom and
lowercase `l` has a tail, so `I`, `l` and `1` look different in file names with codes
in them.
