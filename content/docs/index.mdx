A self-hosted cloud storage platform with file storage and management capabilities.

## Features

- **[Encrypted Storage](/docs/concepts/file-system#storage)** --- Encrypt files with AES-256-GCM in any S3-compatible bucket
- **[Windows Cloud Drive](/docs/getting-started/desktop-app#cloud-drive-mounted-windows-drive)** --- Open and save cloud files from any Windows app
- **[Document Editing](/docs/guides/user/upload-files#document-editing-and-viewers)** --- Edit with OnlyOffice or desktop apps and sync changes back
- **[Controlled Sharing](/docs/concepts/sharing-model)** --- Create read-only links with expiry and a separate domain
- **[Sub-user Access](/docs/guides/user/sub-users)** --- Give each login separate permissions over the same files
- **[Large-file Workflows](/docs/concepts/file-system#large-file-handling)** --- Stream transfers and queue bulk file operations

## Quick Start

Get TMA Cloud running with one command. It needs Docker with Compose v2.

```bash
curl -fsSL https://raw.githubusercontent.com/TMA-Cloud/TMA/main/setup.sh | bash
```

The script creates `./tma-cloud`, fills every password and key with random values, and starts the stack. See [Docker Deployment](/docs/getting-started/docker#setup-script) for what it does, how to read it before running it, and its options.

Once the containers are healthy, open [http://localhost:3000](http://localhost:3000) and create the first account — that account becomes the admin. Then connect a bucket in **Settings** → **Storage** ([Storage Bucket](/docs/guides/admin/storage-bucket)); files cannot be uploaded until one is saved.

Back up the encryption key; stored files cannot be decrypted without it. See [Backups](/docs/guides/operations/backups#encryption-key).
